# CampusFlow
本项目面向校园活动组织与参与场景，构建一个集活动发布、活动发现、组队协作、报名审核、消息通知、签到反馈于一体的协作平台。系统旨在解决当前校园活动报名分散、组队效率低、信息传达不及时、流程管理不闭环等问题，提升活动组织效率与学生参与体验，支持活动全流程数字化管理。

最高优先级原型故事： 
作为学生，我想浏览可报名活动，便于快速找到适合我的活动。 
作为学生，我想创建队伍并邀请队友，便于参加团队活动。 
作为学生，我想申请加入某支队伍，便于完成组队报名。 
作为组织者，我想审核报名/队伍资格，便于控制活动秩序。 
作为参与者，我想接收报名结果与活动提醒，避免错过活动。

迭代 1：活动浏览、详情、创建队伍、加入队伍、报名审核。 
迭代 2：消息提醒、签到、活动结果反馈、队伍管理优化。
